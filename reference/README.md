# الحزمة المرجعية لمشروع «واحة الرياضيات»

هذا المجلد هو الحزمة المرجعية للمشروع كله كما هي: الميثاق والقرارات، والمناهج والوحدات للمراحل الأربع، والمراجعات والتقارير
(ومنها إغلاق كل بوابة وتقارير فحوصها المستقلة بنصّها)، والسجلات، وبنك الأسئلة، والتطبيق القديم، ومواصفات المحرّك ودليل الصوت.

- **ابدأ من** `00_اقرأني_أولاً.md`، ثم `01_الحالة_الحالية.md` و`02_الأخطاء_والتصحيحات.md` والميثاق `02_الميثاق_والقرارات/00_CHARTER_ميثاق_المنهاج_المرجعي.md`.
- **ما تسمّيه الحزمة** `09_محرك_الدروس/مستودع_المحرك/` **هو هذا المستودع نفسه** (جذره)، فلم يُكرَّر هنا.
- الملفات في `09_محرك_الدروس/` (`05_…html`، و`05b_…dev.html`، و`06_…xlsx`، و`فحص_المحرك/`) هي نواتج آخر بوابة كما أُغلقت. والنواتج الحيّة في `dist/` وفي صفحة Releases.
