**6. قاعدة المفتاح (H2 (7)): نجت 10 صيغ من 18 جرّبتُها، ومُنع كودان مشروعان.**
(`_rev/lintmut.py`، الخرج `_rev/out/lintmut.txt`.)
- **نجت:**
  - مستمعٌ بلا معامل يقرأ `event` العام: `() => { if (event.key === ' ') … }`. ومثله `onkeypress = function () {…}`، و`event.which`.
  - `window.event.key` في مستمع له معامل.
  - معاملٌ افتراضي: `(e, k = e.key) =>`. المعاملات بعد الأول لا تُفحص (`build/lint.mjs:159–161`).
  - `el['addEventListener']('keydown', …)`.
  - `addEventListener('key' + 'down', …)`: يبدأ بعلامة، فلا يُمنع ولا يُعرف مستمعاً (`lint.mjs:154–155`).
  - `el['onkeydown'] = …`.
  - `Object.assign(el, { onkeydown: … })`.
  - `e.target.ownerDocument.defaultView.event.key`: ما بعد `e.target` المسموح حرّ.
- **أُمسكت:** keyup باسمٍ معرَّف بعده، و`handleEvent`، و`"Space"` بمزدوجتين، و`e?.key`، والمستمع بـ `let` ثم إسناد، وتعليقٌ قبل الدالة، وتعريف isActKey داخل تعليق، ومستمعٌ ثانٍ باسم.
- **مُنع وهو مشروع:** `if (e.key === 'Escape') return;` و`e.shiftKey` في مستمع مفاتيح. فلا يُكتب إغلاق الغطاء بـ Escape ولا حبس التركيز.
- **الإصلاح:**
