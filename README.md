# واحة الرياضيات — مشروع المحرّك (مصدر التطبيق)

هذا المجلد هو **مصدر** تطبيق «واحة الرياضيات» (الهندسة للأطفال). التطبيق الذي يُعطى للأطفال يبقى **ملفاً واحداً** يعمل دون اتصال
(`dist/واحة_الرياضيات.html`)، لكنه لم يعد يُكتب يدوياً: خطوة بناء صغيرة تجمعه من الأجزاء أدناه (قرار الميثاق D246).

## ماذا في كل مجلد؟

| المجلد | ما فيه | من يلمسه؟ |
|---|---|---|
| `content/` | **المحتوى التعليمي كبيانات** (ملفات JSON مقروءة): النصوص المنطوقة، سجلّ الأخطاء، الوحدات، الدروس | مالك المنهج / الاختصاصي — بلا خوف من كسر الكود |
| `content/strings/gen.json` | الجمل العامة لكل الدروس: المدح، تفسير «حل مشترك»، جمل التحدي والمراجعة والورشة والمعرض والاستراحة (`gen.*`) | |
| `content/strings/labels.json` | أسماء السلال (دائرة، مربع، مكعب…) | |
| `content/errors.json` | **سجلّ الأخطاء الواحد**: لكل وسم خطأ اسمٌ يراه الكبار في اللوحة (`label`)، وأسئلة التلميح الأول التي يسمعها الطفل (`q`)، وحركة الأداة في التلميح الثاني (`vis`) | |
| `content/m1/u1/unit.json` | الوحدة الأولى: العنوان، المضيفون، أشكال صيد الكاميرا، ألغاز الورشة | |
| `content/m1/u1/d1.json` … `d6.json` | كل درس بيانات كاملة (المخطط الثاني): الحقيبة، والجمل، والمسار `flow` بمشاهد من الكتالوج، والتمرين العادي والتحدّي، و«صحّح لفوضى»، والإتقان بمولّداته المستقلة، ومخزون المراجعة، والختام ومهمة البيت، واختبار الوحدة في الدرس السادس | |
| `content/m1/u2/…` | الوحدة الثانية بالطريقة نفسها (ستة دروس، D248) | |
| `src/` | **كود المحرّك**: `head.html` و`styles.css` و`body.html` وJS في `src/js/` مقسّمة بحسب المسؤولية (الصوت، الرسم، الأدوات، الدروس، المشغّل، الورشة، لوحة الكبار…) | المهندس |
| `build/` | خطوة البناء: `build.mjs` (الدمج)، `lint.mjs` (فحوص المحتوى)، `script.mjs` + `script_xlsx.py` (جدول التسجيل الصوتي)، `clips.mjs` (جمع الجمل) | المهندس |
| `assets/fonts/` | مكان ملف الخط `BalooBhaijaan2.woff2` إن أردنا تضمينه | |
| `test/` | أدوات الفحص الآلي (Playwright)؛ و`test/legacy_v1/` أدوات فحص الانتقال من الملف القديم (D249)، لا تنطبق على المحرّك v2 | المهندس |
| `dist/` | **الناتج**: الملف الواحد للأطفال، ونسخة الفحص، وجدول التسجيل | يُولَّد آلياً؛ لا يُحرَّر |
| `docs/SCENES.md` | **مرجع المحرّك v2**: مخطط الدرس، وكتالوج المشاهد، ولغة الخطوات، وأنواع البنود، والفحوص، ووضع الفحص | |
| `docs/MIGRATION.md` | خارطة الانتقال (تاريخية: نُفّذت في بوابة هـ) | |

## كيف أبني الملف؟

يلزم Node (الإصدار 18 فأعلى) فقط. من داخل مجلد المشروع:

```
node build/build.mjs
```

يُنتج `dist/واحة_الرياضيات.html` (نسخة الأطفال) ويطبع:

1. **نتيجة فحص المحتوى**: عدد الجمل والأخطاء والدروس، وأي مخالفة توقف البناء (جملة بلا نص، صيغة مخاطبة ناقصة، معرّف مكرّر، وسم خطأ بلا تفسير…).
2. حالة **الخط**: مضمّن أو لا.
3. **جدول التسجيل** `dist/script_m1.xlsx` (يلزم له Python مع openpyxl؛ وإن لم يتوفّر يُكتب `dist/script_m1.json` فقط).

نسخة الفحص (تُبقي خطافات الفحص الآلي ووضع `#fast` الذي يقصّر الانتظار):

```
node build/build.mjs --dev
```

تُنتج `dist/واحة_الرياضيات.dev.html`. **لا تُعطى هذه النسخة للأطفال.**

لتشغيل فحوص المحتوى وحدها دون بناء: `node build/lint.mjs`.

## كيف أشغّل الفحوص؟

تلزم Python 3 مع `playwright` (ومتصفح Chromium مثبّت له) و`openpyxl`.

| الأمر | ماذا يفحص |
|---|---|
| `node build/lint.mjs` | المحتوى (انظر `docs/SCENES.md`، القسم 6) |
| `python3 test/smoke_prod.py` | نسخة الأطفال بالزمن الحقيقي: البداية بلا قراءة، والخريطة باثني عشر درساً، والحقيبة، والمشهد الأول، ولمسة تتقدّم بها الجملة، ولا خطافات فحص ولا أخطاء ولا حركات تالفة |
| `python3 test/flows_run.py` | ما خارج الدرس، بالوضعين النهاري والليلي: ترحيل التقدّم القديم، والخروج الآمن والاستئناف، والاستراحة وبوابة الكبار، و«أرقامي»، والمعرض والصورة، ولوحة الكبار، وأهداف اللمس، وأن كل جملة منطوقة في جدول التسجيل |
| `python3 test/auto_run.py <نمط> <مسار> <جنس>` | السائق الآلي على الدروس الاثني عشر والورش ومراجعة اليوم. النمط: `ok` (كل جواب صحيح)، و`mixed` (أول خطأ لكل نوع بند)، و`deep` (أربعة أخطاء لكل نوع: التلميح الثلاثي والتوأم)، و`failmastery` (الإتقان يُخفق: دورتان ثم تأجيل)، و`failtest` (اختبار الوحدة يُخفق ثم يُعاد)؛ والمسار `mat` أو `screen`؛ والجنس `f` أو `m`. ويطبع أخطاء الصفحة، وأخطاء التقييم، وأهداف اللمس الصغيرة، والجمل التي ليست في جدول التسجيل. `SHOTS=1` يحفظ صورة لكل مشهد في `test/out/auto/` |
| `sh test/run_all.sh [مجلد]` | المجموعة كلها: البناءان، والدخاني، والمسارات، وستة تشغيلات للسائق الآلي؛ النتائج في `test/out/all/*.txt` |

## كيف أعدّل جملة أو أضيف درساً؟

**تعديل جملة:** افتح ملف JSON المناسب (الدرس أو `gen.json` أو `errors.json`)، وعدّل النص فقط، وأبقِ المعرّف (مثل `"hook.01"`) كما هو لأن ملفات الصوت تُسمّى به.
صيغتا المخاطبة تُكتبان بين قوسين مع شرطة: `{اِلْمَسْ|اِلْمَسِي}` (الولد أولاً ثم البنت)، واسم الطفل `{name}`. والعدد في الجملة المنطوقة كلمةٌ لا رقم. ثم `node build/build.mjs` — وإن أخطأت أوقفك الفحص وأخبرك بالمكان.

**إضافة درس:** الدرس كله بيانات. انسخ درساً شبيهاً وعدّل حقوله كما في `docs/SCENES.md` (القسم 1): الحقيبة، والجمل، والمسار بمشاهد من الكتالوج (القسم 3) أو بنود (القسم 5)، والتمرين، وفوضى، والإتقان بمولّدات **غير** مولّدات التمرين، ومخزون المراجعة، والختام. والمولّدات أسماء من `src/js/35_makers.js` أو أشكال صريحة. البناء يرفض الدرس إن أشار إلى مشهد أو مولّد أو جملة أو وسم غير موجود، أو خالف D240.
**مشهد جديد** (حين لا يكفي الكتالوج): يُكتب في `src/js/45_scenes.js` ويُضاف إلى جدول الكتالوج في `docs/SCENES.md`، ويسجّل حلّه لوضع الفحص بـ `AUTO(...)`.

**إضافة خطأ جديد:** أضف إلى `errors.json` مدخلاً `"tagName": { "label": "ما يراه الكبار", "q": { "gen.err.tagName.01": "سؤال يسمعه الطفل لا يذكر الجواب" }, "vis": "edges" }` ثم استعمل الوسم في `sort.errors` للدرس أو في `err` البند.

## كيف أضيف ملف الخط؟

1. نزّل خط **Baloo Bhaijaan 2** (رخصة OFL) بصيغة `woff2` (يفضَّل مجموعة جزئية عربية + أرقام لتصغير الحجم).
2. ضعه باسم `assets/fonts/BalooBhaijaan2.woff2`.
3. `node build/build.mjs` — سيطبع «الخط: مضمّن»، ويُحذف رابط Google من الملف، فيعمل الخط دون اتصال.

إن لم يوجد الملف، يبقى الرابط غير الحاجب كما هو مع بدائل خطوط النظام العربية.

## ملاحظات

- **لا تحرّر `dist/` يدوياً**؛ أي تعديل يُكتب في `content/` أو `src/` ثم يُعاد البناء.
- المحتوى بالعربية الكاملة التشكيل كما في جدول التسجيل؛ المعرّف ثابت والنص قابل للتغيير.
- `dist/script_m1.xlsx.ids.json` هو قائمة أسماء ملفات الصوت المطلوبة (`m1.u1.d1.hook.01.mp3`، و`_m`/`_f` للجمل ذات الصيغتين).
