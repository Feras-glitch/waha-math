# مواصفة محرّك الدروس الجديد (D179)

> **الحالة:** 1.4 · 26 أكتوبر 2026 (القسم 15: بوابة S1-U4، الميثاق 1.64، D258). وكانت 1.3 · 22 أكتوبر 2026 (القسم 14: بوابة S1-U3، الميثاق 1.63، D257)، و1.2 · 21 أكتوبر 2026. الأقسام 1–12 تصميم الإصدار 1.0 وإضافات الميثاق 1.51–1.52 كما كُتبت؛ **والقسم 13 يصف المحرّك المنفَّذ بعد بوابة هـ (D216، D250) وإصلاحات فحصها المستقل (الميثاق 1.62، D252–D256)، وحيث يختلف عن الأقسام السابقة فهو الأصل** (جدول 13.8).
> **الهدف:** طفل من 6 إلى 14 سنة يتعلّم الدرس ويحلّ تمارينه **وحده**، ودور الكبير إشراف فقط.
> **القيود:** ملف HTML واحد يعمل دون اتصال، وحزم صوت خارجية اختيارية تُستورد مرة واحدة، ولا خادم.

## 1) لماذا محرّك جديد؟

المحرّك الحالي يعرض لكل درس **مهمة واحدة**: اختياراً أو فرزاً، تسبقها جملة تمهيد. والشرح كان مطويّاً. وهذا لا يمكن ترقيعه إلى درس، لأن البيانات نفسها لا تحمل مراحل الدرس:

```
title, intro, items, bins, hints, done
```

المحرّك الجديد يجعل **بنية الدرس في الميثاق** (القسم 5) بنيةَ بيانات. كل درس «سيناريو مشاهد»، وكل مشهد يستعمل أداة تفاعلية يُعاد استعمالها عبر المنهاج.

## 2) حلقة الدرس (7 مشاهد، 8–15 دقيقة، وتُقسم في م1 على جلستين)

| المشهد | المفتاح | ما يحدث | الصوت |
|---|---|---|---|
| ① إشعال | `hook` | «فوضى» ترتكب خطأً شائعاً في مشهد من المدينة (30–45 ث) | فوضى + فرجار |
| ② اكتشاف | `explore` | الطفل يستعمل أداة: يطوي، يقيس، يبني، يدوّر. والأداة تُظهر النتيجة. هدف واحد واضح | فرجار يوجّه |
| ③ مثال محلول | `worked` | خطوات متحركة مسموعة، والطفل يضغط «التالي». كل خطوة فيها «لماذا» | فرجار |
| ④ حاول أنت | `practice` | 3–5 مسائل 🟢🟡🟠 من مولّد. **كل خيار خاطئ موسوم بخطئه**، فالتغذية الراجعة تفسّر | فرجار + تغذية متنوعة |
| ⑤ صحّح لفوضى | `fixChaos` | فوضى تحلّ مسألة بخطأ شائع، والطفل يحدد أين أخطأت ولماذا | فوضى |
| ⑥ فحص إتقان | `mastery` | 3 مسائل جديدة بلا تلميح، تُحسب من المحاولة الأولى. 3 من 3 تعني متقناً (D178، D182) | — |
| ⑦ ختام | `wrap` | ملخص بجملة، وقطعة للمدينة، ونشاط بلا شاشة اختياري | فرجار |

**قواعد حاكمة:**
1. **لا اختبار قبل تعليم:** ② و③ إلزاميان في أول مرور، ويُتخطَّيان في المراجعة أو إذا كان التشخيص 🟢.
2. **المحاولة الأولى هي البيان:** التجريب يُكمل التمرين ولا يحتسب إتقاناً.
3. **كشف الجواب لا يُنهي:** بعد «الحل المشترك» (التلميح 3) تأتي **مسألة توأم** إلزامية.
4. **مبادرة المرشد:** إن لم يتفاعل الطفل 20 ثانية سأله فرجار: «هل نفكّر معاً؟».
5. **لا مؤقّت إجباري** (D42)، و**لا «أخطأت»**؛ القاعدة دائماً «فكّر معي».
6. **التحقق بالأداة لا بالعين** (المبدأ 6 في D03): بعد الإجابة تُظهر الأداة لماذا، بطيٍّ أو قياس أو عدّ.

## 3) بنية بيانات الدرس

مثال مختصر: درس «الدائرة والمربع» من S1-U1.

```js
LESSON('m1.u1.d1', {
  title: 'الدائرة والمربع',
  concepts: ['C001', 'C004'],          // تُربط بالسجل
  minutes: 10,
  hook: { scene: 'park', lines: [
      { who: 'chaos', id: 'hook.01', text: 'هذه البلاطة دائرة! انظروا… أوه، دوّرتُها فصارت دائرة!' },
      { who: 'compass', id: 'hook.02', text: 'هل تغيّر شكلها حقاً حين دوّرتها؟ تعالَ نتحقق معاً.' } ] },
  explore: { tool: 'traceEdge', setup: { shapes: ['circle', 'square'] },
      goal: { id: 'exp.goal', text: 'مرّر إصبعك على حافة كل شكل. أيّهما فيه أركان؟' },
      check: 'countedCorners', reveal: { id: 'exp.reveal', text: 'المربع له ٤ أركان، والدائرة لا أركان لها.' } },
  worked: { tool: 'shapeBoard', steps: [
      { id: 'wk.01', text: 'نعدّ الأركان: واحد، اثنان، ثلاثة، أربعة.', anim: 'countCorners(square)' },
      { id: 'wk.02', text: 'ندوّر المربع… ما زال له ٤ أركان، فهو ما زال مربعاً.', anim: 'rotate(square,45)' } ] },
  practice: { gen: 'sortCircleSquare', levels: ['upright', 'rotated', 'sizes'], n: 4 },
  fixChaos: { gen: 'sortCircleSquare', chaosError: 'rotatedSquareIsNotSquare' },
  mastery:  { gen: 'sortCircleSquare', n: 3, firstTry: 3 },
  wrap: { id: 'wrap.01', text: 'الدائرة حافتها منحنية بلا أركان، والمربع له ٤ أركان مهما دوّرناه.',
          cityPiece: 'fountain', offline: 'ابحث في بيتك عن ٣ أشياء دائرية و٣ مربعة.' }
});
```

- **المعرّف الكامل لكل جملة صوتية** = معرّف الدرس + معرّف الجملة، مثل `m1.u1.d1.hook.01`. هذا هو اسم ملف التسجيل (الدليل الصوتي، القسم 3).
- **النص المعروض يُكتب مرة واحدة.** نسخة النطق المشكولة يضيفها اختصاصي اللغة في حقل `tts` عبر جدول الإنتاج (القسم 7)، فلا يُحرَّر الكود يدوياً.
- **الجنس:** تُفضَّل الصياغة المحايدة. وحين يلزم التمييز يُكتب البديلان صراحة بالصيغة `{m:'…', f:'…'}`، ويُلغى التحويل الآلي الحالي الذي يفسد الصفات.
- **الأرقام** تُكتب في المصدر بنمط واحد، والعرض يحوّلها حسب اختيار الطفل (D180).

## 4) المولّدات والتغذية الراجعة الموسومة بالخطأ

كل مولّد يعيد مسألة **ومشتّتات موسومة**:

```js
GEN.reflectPoint = (lvl) => ({
  ask: { id: 'q.reflect', text: 'أين صورة النقطة أ في المرآة؟' },
  tool: 'mirrorGrid', state: { /* … */ },
  answer: [9, 1],
  distractors: [
    { val: [5, 1], err: 'onAxis' },              // وضعها على المحور
    { val: [1, 1], err: 'noReflection' },        // لم تتحرك
    { val: [9, 9], err: 'flippedBothAxes' } ],
  twin: () => GEN.reflectPoint(lvl)              // مسألة توأم بعد كشف الجواب
});
```

- **مكتبة الأخطاء الشائعة** `ERR` تحوي لكل وسم: تفسيراً قصيراً، وتلميحاً بصرياً (حركة الأداة التي تبيّن الخطأ)، وجملة صوتية `err.<وسم>.01..03`.
- **التغذية الراجعة إذن تفسيرٌ مخصص:** «فكّر معي: النقطة وصورتها على بُعدين متساويين من المرآة، وأنت وضعتها على المرآة نفسها». بدل «فكّر معي.» العامة.
- **ضد الرتابة:** لكل حدث عام (صواب، محاولة ثانية، إنجاز، عودة بعد غياب) **8–12 صيغة صوتية** تتناوب، ولا تتكرر صيغة في جلستين متتاليتين، وفيها لمسات فكاهة من فوضى بقدر.
- **بنك الأسئلة الحالي** (`CB`) يُنقل إلى صيغة المولّد تدريجياً، ويُضاف لكل بند حقلا `err` للمشتّتات و`steps` بخطوتين حقيقيتين على الأقل.

## 6) نموذج الإتقان والبيانات (D182)

```js
state.concepts[cid] = {
  level: 0..3,                  // 0 لم يبدأ، 1 مدخل، 2 تأسيس، 3 إتقان (اللولب في الميثاق)
  attempts: [{ t, item, firstTry: true|false, err: 'onAxis'|null, ms }],
  mastery: { ok: true, at: date },
  due: date, ivl: 1|3|7|21     // مراجعة متباعدة
}
```

- **الشارة** = إتقان كل مفاهيم الوحدة + مهمة الأداء. و**قطعة المدينة** لكل مفهوم يُتقن.
- **إشارات للمشرف** تُحسب من `attempts`:
  - **عالق:** 3 أخطاء متتالية في المفهوم نفسه.
  - **يخمّن:** إجابات أسرع من 2 ثانية مع خطأ.
  - **متوقف:** 5 أيام بلا نشاط.
- **ملفات متعددة للأطفال على الجهاز** (لازمة للتجربة المدرسية)، و**تصدير مجهول الهوية** للبيانات لتحليل التجربة (القسم 8 في خطة التجربة).

## 7) سلسلة الإنتاج: من النص إلى الصوت إلى التطبيق

```
كتابة الدرس (JSON)
   ↓  أداة «تصدير النصوص» تنتج جدول Excel لكل وحدة
اختصاصي اللغة والتربية: يراجع، ويشكّل، ويوحّد المصطلحات، ويضع الإرشاد الأدائي
   ↓  أداة «استيراد المراجعة» تعيد النصوص المعتمدة وحقل tts إلى الدرس
المدبلجون: يسجّلون وفق الجدول، واسم كل ملف = معرّف الجملة
   ↓  حزمة صوت لكل مرحلة
التطبيق: يستورد الحزمة مرة واحدة إلى IndexedDB، ويعمل دونها بصوت الجهاز
   ↓  أداة «فحص الحزمة» تبيّن الجمل التي بلا تسجيل والتسجيلات التي بلا جملة
```

التفاصيل في `02_دليل_الإنتاج_الصوتي.md`.

## 8) نظام التصميم (يُبنى مع المحرّك)

- **خطوط عربية مضمَّنة في الملف** (مجموعة جزئية بترخيص OFL) لتعمل دون اتصال: خط عرض مستدير للعناوين، وNoto Naskh Arabic للنص.
- **شاشات الطفل خمس بدل 21:** «تابع» (الزر الأكبر)، والخريطة، والمدينة، والتمرين الحر، والمختبر. ومنطقة الكبار خلف الرمز السري.
- **أهداف اللمس:** لا تقل عن 64 بكسل في م1 و48 بعدها. أيقونات SVG بدل الرموز التعبيرية في عناصر التحكم.
- **لا تُستعمل ألوان الشخصيات في مهام التصنيف والتقييم،** حتى لا يُصنَّف الشكل بلونه.
- **حركة هادئة** تحترم `prefers-reduced-motion`، و`aria-live` للتغذية الراجعة، وتركيز مرئي، ومهام السحب لها بديل بالنقر وبلوحة المفاتيح.

## 9) ضمانات الجودة (تُشغَّل آلياً قبل اعتماد أي وحدة)

1. **صحة المحتوى رقمياً:** هندسة الرسوم (زوايا وتوازٍ وأطوال وأقطار)، وإعادة حساب كل إجابة، وطيّ الشبكات.
2. **كشف الجواب:**
   - طول الخيار الصحيح مقارنة بغيره.
   - كلمات «(خطأ)» و«دائماً» و«فقط».
   - تطابق رسم السؤال ورسم الخيار.
   - اسم العنصر يحمل اسم سلّته.
3. **المفردات:** قائمة مسموحة لكل مرحلة، تمنع مثلاً «متوازي أضلاع» في م1 والعشري في م2.
4. **التكرار في المعنى** بالنص المطبَّع (`qKey`).
5. **التوازن:** لا مفهوم بأقل من 5 أسئلة فهم حقيقية، ولا وحدة بأقل من حدّ أدنى.
6. **الصوت:** كل جملة لها تسجيل في الحزمة، أو تُعلَّم بأنها تعتمد صوت الجهاز.
7. **الانحدار:** إكمال كل الدروس عبر الواجهة، و`cmpset`، واختبارات اللمس.

## 13) المحرّك v2 بعد بوابة هـ (الميثاق 1.62، D250، D252–D255)

### 13.1 المصدر والبناء
- المصدر الوحيد `مستودع_المحرك/` (D249): `src/js/` خمس وعشرون وحدة مرتّبة بالأرقام، و`content/` بيانات JSON كاملة، و`build/build.mjs` يُخرج ملفين: `dist/واحة_الرياضيات.html` للأطفال بلا خطافات فحص (البناء يرفض أي بقايا)، و`dist/واحة_الرياضيات.dev.html` للفحص. ويولّد البناء جدول التسجيل `dist/script_m1.xlsx` (966 جملة، 1296 ملفاً صوتياً بصيغتي المخاطبة)، والجدول ثابت البايتات: بناءان من المصدر نفسه يعطيان الملف نفسه.

### 13.4 الصلاحية آلياً (`build/lint.mjs` يوقف البناء)
الجمل كلها موجودة وبصيغتيها، ولا رقم في جملة منطوقة، ولا جملة درس غير مستعملة، ولا اسم شيء أو خيار أو تعليل «لا سلّة لنوعه» لا يبلغه المحتوى (ولا ما يبلغه بلا جملة)؛ وكل مشهد ومولّد ونوع بند معروف؛ ولكل مفهوم ثلاثة بنود، والاختبار من دروس وحدته؛ و**D232** الرأس؛ ولا `Math.random` بلا علامة؛ ولا كود بعد تعليق السطر.

**`build/d240.mjs` (D240، D253):** يجمع لكل بند تقييم (الإتقان، والمراجعة المحجوزة، والبند المشتبك، واختبار الوحدة) «موضوعه»، أي ما يحكم عليه الطفل، ويقارنه بكل ما عُرض في الدرس (المثال المحلول، والاكتشاف، والإشعال، والتمرين واللعبة، و«صحّح لفوضى»، والتذكّر والعلاج، والتوأم) بثلاث طرق: **بالاسم** (المولّد نفسه)، و**بالهيئة في المهمة نفسها** (`نوع|وضع|شيء|دوران|نسبة`، تُقرأ من سطر تعريف المولّد في الكود فلا قائمة ثانية تتقادم؛ والمهام: تصنيف، وعدّ، ووجوه، ودفع)، و**بالنصّ** (بعد حذف مفاتيح الصياغة). والبند المشتبك يُقارَن بدرسه، وبند الاختبار بدرسه وبالدرس السادس. **وما حُلّ في تقييم سابق** يُقارَن بهيئته في المهمة وبنصّه: الإتقان للمراجعة، والإتقان والمراجعة للبند المشتبك والاختبار، وبنود الوحدة المشتبكة للاختبار. و**المسألة العددية** بأعدادها وجوابها لا تُقيَّم بعد أن حُلّت وإن تغيّر عرضها أو نوع بندها: الضمّ والجملة والقصة مسألة جمع واحدة بعدديها، والإبعاد والجملة مسألة طرح واحدة، والتفكيك بجزأيه، والمقارنة بعدديها، والعدّ بعدده بين التقييمات؛ **وما يعرضه المشهد من أعداد بجوابها** (رفّا `shelvesWalk`، وصناديق `mailExplore`، وبرجا الإشعال والمثال المحلول وجملته) معروضٌ كذلك (`SCENE_FACTS` و`STEP_FACTS`). و**مخزون المراجعة محجوز بالشيء لا باسم المولّد:** الظرف المائل والظرف شيء واحد، فلا يظهر في درس آخر من الوحدة بأي مولّد له. و**ما يرسمه المشهد بنفسه** معروضٌ (`SCENE_DRAWS`: عجلات العربتين، وبابا الزرافة؛ وكل مشهد في الكود مسجَّل فيها أو في `SCENE_NONE`، وإلا توقّف البناء). و**مخزون المراجعة محجوز في الوحدة**: مولّده لا يظهر في درس آخر منها ولا في توأم ولا في اختبار. وصور أشياء الحقيبة ومولّدات العدّ الصغيرة مستثناة، وأي استثناء آخر يُكتب في البند بمفتاح `x240` مع سببه. ويفحص كذلك: لكل مفهوم بند إنتاج أو تعليل، ولكل «تأسيس» فحص إتقان (إلا المدخل)، ولا لون هوية (`$solid.` و`$id.`) فيما يُصنَّف في «صحّح لفوضى» والفرز والاختيار (D41)، ولكل درس تمرين بعادي وتحدٍّ (D239)، ولكل بند مراجعة مفهومه ولكل مفهوم يُراجَع بندان (المبدأ 14، D253 (7)). و`D240_DUMP=<درس>` يطبع للمؤلّف ما رآه الطفل وحلّه في الدرس.

### 13.5 الأسس التقنية (D246)
- **التخزين** بتحقق النوع، والتالف يُنسخ، وفشل الكتابة يُعلَن في اللوحة؛ و**إصدار البنية** `schema = 3`: تقدّم من بنية أقدم يُحفظ كاملاً ويبدأ من جديد مع تنبيه للكبير.
- **العشوائية** بذرة لكل تشغيل درس (الطفل والدرس ورقم التشغيل) ولكل ورشة ومراجعة يوم، تُسجَّل مع كل محاولة فيُعاد بناء ما رآه الطفل.
- **غلاف حركة واحد** `anim()` يحترم تقليل الحركة ووضع الفحص، ويحوّل صيغة `transform` من سمة SVG إلى CSS.
- **أهداف اللمس بالبكسل الفعلي (D255):** 56 بكسلاً لما يلمسه الطفل، و64 لما يُسحب، و44 لرابط الكبار ولوحته. وإن تراكبت المناطق فاللمسة لأقرب هدف وقع اللمس فعلاً على رسمه أو منطقته (`tapAll` بـ `elementsFromPoint`، والبعد إلى القطعة المستقيمة لهدف هو خطّ كضلع المثلث، لا إلى إطاره)، أو لأصغر مكان يقع اللمس داخل رسمه (`houseMatch` و`insideShape`)، أو تُوجَّه منطقة واحدة إلى أقرب مكعب في البرج المكدّس (`rect.route`)؛ وفي «لمس واحد» (`tapOne` بـ `tapRoute`) لأعلى رسمٍ مرئي لهدف تحت الإصبع، فإن لم تقع إلا على مناطق شفافة فلأقرب هدف إطارُ رسمه إليها (`drawnBox`)، ويحجب ما تحته شيءٌ مرئي ليس هدفاً؛ و«لمس واحد» يزيل عند الجواب ما أضافه من مناطق، واللمسة على هدف داخل هدف لأعمقهما؛ والأشياء الكبيرة المبعثرة في «ابحث في الغرفة» (`roomThings`) في صفّين مبعثرين (`layoutPts(n, 'rows', cx, cy, 130)`: في كل صف تتوزّع الأشياء على عرض 264 (هامش 13 من حافة المسرح) بفراغات عشوائية لا تقلّ بين جارين عن 90، ويبعد الصفّان 130 بهزّة رأسية ±20، فلا يقترب شيئان في المحورين معاً أكثر من منطقة لمس الشيء)، والشيء الذي يُسأل عنه إن غاب يحلّ في موضع عشوائي، والغرفة تسع ستة أشياء، ولكل نوع يُسأل عنه شيء منه (يفحصهما فحص المحتوى من سطر كل مولّد)؛ ولغز المتجر لا شيء فيه يُسحب؛ ولا تحجب قطعةٌ لا تُعدّ قطعةً تُعدّ (الروبوت)، ولا قطعةٌ وُضعت في البيت مكاناً فارغاً (تنزل إلى طبقة تحت الأماكن وتفقد منطقتها). ومستمعات أداة التتبّع تُزال بعدها، فلا يبقى التقاط المؤشّر يأخذ نقرة الفأرة من الأضلاع. `hitPad(g, وحدات، بكسل)` يحسب المنطقة بمقياس الشاشة الحقيقي (`pxPerUnit`) من رسم الشيء وحده (تُخفى كل منطقة فيه عند القياس)، ولكل شيء منطقة واحدة يعيد تحجيمها كل استدعاء جديد بأكبر الحدّين فلا تتكدّس المناطق مع كل سؤال، و`ResizeObserver` على المسرح يعيد حسابها كلما تغيّر حجمه (`sizePad`/`refreshPads`)، و`faceSize` يكبّر المجسّم الذي تُلمس وجوهه حين يصغر المسرح. وعلى الشاشة القصيرة أو الضيقة (`max-height:700px` أو `max-width:380px`) تثبت فقاعة الدرس (`#bubble`، لا فقاعات الأغطية) على ثلاثة أسطر تُمرَّر، ويأخذ المسرح ما بقي فلا يتغيّر حجمه مع طول الجملة؛ ويُخفى الرفيق تحت 340 بكسلاً عرضاً.
- **أسماء aria** لكل ما يُلمس، و`aria-live` للفقاعة، وتركيز مرئي بلوحة المفاتيح وحدها (لا إطار برتقالي بعد اللمس على عناصر SVG)، وأماكن البيت تُختار بلوحة المفاتيح، والوضع الليلي.
- **الخيارات المقروءة** (`readChoices`، وتمرّ بها كل قراءة خيارات: أزرار الاختيار، وأسماء السلال، و«أضف/أبعد»، وأعداد الاختيار `numberPick`، وبطاقتا الجملة العددية): الخيار المقروء لا يصير «آخر جملة» ولا يغيّر نصّ الفقاعة (`keep`)، و«أعد الجملة» ما دامت الخيارات على الشاشة يعيد السؤال ثم الخيارات. والعدد الذي يتمّ السؤال («ضعي في السلّة: ثمانية»، «المسي بطاقة العدد: صفر»، والجملة العددية كلمةً كلمة) يُكتب في الفقاعة مع السؤال (`append`)، و«أعد الجملة» يعيدهما معاً.
- **الخطّان (D232، D256):** خط القراءة `--f` (Waha Naskh، مقتطع من Scheherazade New بوزنين 400 و700) لكل ما يقرؤه الطفل، ومنه نصوص الرسوم؛ وخط العناوين والأزرار الكبيرة `--fd` (Baloo Bhaijaan 2). يضمّنهما البناء دائماً من `assets/fonts/` (تكتبها `tools/fonts/make_fonts.py` من ملفات Google Fonts الرسمية)، ويتوقف إن ظهر حرف عربي أو لاتيني لا يغطّيه خط القراءة. واسم Scheherazade محجوز في ترخيص OFL والاقتطاع تعديل، فالمقتطَع باسم آخر.
- **قفل التبويب** (تبويبان لا يمحو أحدهما عمل الآخر)، و**ماسك الأخطاء** (رسالة مسموعة وعودة إلى الخريطة، والخطأ في سجل اللوحة).

### 13.6 الفحص
`sh test/run_all.sh`: البناءان؛ والفحص الدخاني لنسخة الأطفال بالزمن الحقيقي؛ و`flows_run.py` لما خارج الدرس بالوضعين (الترحيل، والخروج والاستئناف، والاستراحة والبوابة، و«أرقامي»، ولا رقم على الخريطة قبل درس الأرقام، والمعرض، واللوحة، وأهداف اللمس، ومطابقة الجمل لجدول التسجيل)، وعلى 320×568 أن غطاءَي الترحيب والخروج داخل العرض وفقاعتيهما كاملتان، وباسم من كلمتين «عبد الرحمن» على الشاشات الثلاث أن الخريطة وغطاء الاستراحة فوقها داخل العرض المرئي ولا يغطّي صفٌّ ما تحته؛ و`replay_run.py` لـ«أعد الجملة» (بعد الخروج من كل نوع انتظار، وأثناء جملة بالزمن الحقيقي، وأثناء قراءة البطاقتين بالترتيبين، وسؤال التعليل، وبعد قراءة الخيارات والسلال: يعيد السؤال ثم الخيارات والفقاعة على السؤال)؛ و`build/lint.mjs` يرفض كل عدد يُقال كلمةً خارج 0–10 في البنود والمشاهد (ومنها بديل جملة الطرح، والجزء الآخر، والبرج الأكثر بواحد)، وبند تعليل صحيحه أطول من 1.2 × أطول مشتّتيه؛ و`build/d240.mjs` يرفض لون شيء ثابت على أقل من ΔE2000 = 12 من لون هوية سلّته، ويقارن بند الاختبار بدروس الوحدة كلها؛ و`realtap_run.py` **باللمس الحقيقي** على الشاشات الثلاث (`touchscreen.tap` في المركز المرئي لكل هدف، وأحداث لمس حقيقية للسحب عبر CDP بسرعة إصبع تقف على السلّة قبل الرفع، لأن المتصفح نفسه يُسقط النقرة التي تلي «رمية» بأقل من نحو ثلث ثانية، وبالفأرة `MOUSE=1`): لمس كل هدف في انتظارات اللمس والعدّ والبيت (بالترتيبين)، و**سحب** كل شيء إلى سلّته، ووضع العدد قطعةً قطعة، وتلوين البرج، ويطلب أن ينتهي الانتظار بجواب صحيح، ويخرج بـ 1 إن أخفق (وكذلك `replay_run.py` و`flows_run.py`)؛ و`layout_run.py` يشغّل «ابحث في الغرفة» نفسه ستين جولة على كل شاشة من الثلاث (بمحاولتين خاطئتين في كل ثالثة، وتدوير الشاشة وإعادتها) ويرفض تراكب رسمين، أو مركزاً يأخذه غيره، أو أكثر من منطقة لشيء، أو منطقة تبلغ رسم الجار، أو منطقة كبرت عن المحاولة الأولى؛ ويلمس بالإصبع شيئين متراكبين عمداً لكل زوج من أشياء الغرفة العشرة (بشرط أن منطقة الثاني فوق مركز الأول)، ونقطتين على منطقتين شفافتين بين شيئين متجاورين (الأقرب رسماً، ويُشترط أن يكون الأسفلَ عشر مرات على الأقل)، وشيئاً مرئياً ليس هدفاً بين منطقتين (لصاحب المنطقة التي فوقه)؛ ويعدّ موضع الشيء المسؤول عنه في 300 غرفة (الخانات الست بالتساوي تقريباً) ويطلب أن ترفض الغرفة سبعة أشياء؛ ويطلب كل رسم داخل المسرح بهامش 8 وحدات، وهدفاً داخل هدف لأعمقهما، وشكلاً لا يُرى (شفافيته صفر) لا يأخذ لمس رسم تحته، و`hitPad` مرتين على الشيء نفسه منطقة واحدة، وضمانات التخطيط في 5000 غرفة؛ و`sort_errors.py` لكل حكم فرز ممكن (لا خطأ يسقط إلى الوسم العام، ولا تعليل ينفي نوع الشيء في البند المشتبك)؛ والسائق الآلي `auto_run.py` على الدروس الاثني عشر **بسبعة أنماط** (`ok`، و`mixed`، و`deep`، و`failmastery`، و`failtest`، و`replay`، و`failreview` للمبدأ 14) وبمساري الحقيبة والجنسين، وبالوضع الليلي (`DARK=1`)، وعلى ثلاث شاشات (`DEVICE`: Pixel 5 بـ 393×727، وGalaxy S5 بـ 360×640، وiPhone SE بـ 320×568). ويفحص السائق في كل مشهد: أخطاء الصفحة، والأهداف الأصغر من 56 بكسلاً (و64 لما يُسحب)، والأهداف بلا اسم، و**مركز كل هدف يذهب إليه هو** (`tap conflicts`: لا يسرقه هدف آخر إلا قطعة متماثلة في مكانها، ولا يحجبه شيء)، وبطاقتا فوضى مخفيتان متماثلتان، وتسرّب نصّ جملة فوضى إلى الشاشة قبل كشفه أو بعد «أعد الجملة»، وكل جملة منطوقة غير موجودة في جدول التسجيل، وما يُسحب ولا رسم فيه (`empty drags`)، والدروس التي توقّفت أو دارت في حلقة أو لم تنتهِ (`blocked lessons`، `lessons not done`). وتكتب المجموعة `test/out/all/SUMMARY.txt`: كل فحص خرج بـ 1، وكل عدّاد للسائق غير صفر (إلا أخطاء التقييم المقصودة في أنماط الإخفاق)، وتخرج بـ 1 إن كان فيها شيء. ثم `unspoken.py` يجمع الجمل المنطوقة في التشغيلات كلها ويطبع ما لم يُنطق منها، تقريراً قبل التسجيل. وكل فحص جديد جُرِّب على نسخة فيها الخطأ القديم قبل اعتماده (الدرس 98). وأدوات فحص الملف القديم في `test/legacy_v1/` للتاريخ.

### 14.3 الصلاحية آلياً (إضافة إلى 13.4)
- **حقائق بنيوية في `d240.mjs`** لكل مسألة مكانية (D257 (2))، فلا يُقيَّم ما عُرض أو حُلّ بالمهمة نفسها وإن تغيّر الشيء؛ والخريطة بخانة الجواب وعلاقتها لا بالغرفة كلها، والطريق بما يمرّ به (الفحص المستقل C)؛ ومسألة المراجعة محجوزة في الوحدة كلها؛ ومسألة التوأم غير مسألة أصله ولا مسألةٍ حُلّت قبله في الإشعال والاكتشاف، ولا مسألة بندٍ آخر بمساعدة في درسه (التمرين والتحدّي واللعبة والعلاج، الفحص المستقل D)، ومسائل التوائم معروضة.
- **في `lint.mjs`:** لا عدد فوق العشرة قبل طريق الأعداد، ولا قطار أطول من الأعداد الترتيبية المسموعة، ولا عربة خارج قطارها؛ وخانة «أين الكنز؟» فارغة لا يحجبها قريب منا، و«تحت» لطاولة قريبة منا وحدها؛ وبطاقتا «أيّ أمر نفّذ؟» و«أيّ وصف يناسب الطريق؟» لا يدلّ طولهما على الصحيحة؛ ولكل نوع بند توأم، ولكل بند بمساعدة من نوعٍ توأمُه في بياناته توأم؛ ولكل موضع يُطلب جملة حلّه وكلمته وجملة كشفه، والكشف لا يقول جملة حلّ؛ ووسوم الأخطاء في البيانات موجودة. **وبعد الفحص المستقل C:** الساكن قبل همزة الوصل يُحرَّك؛ وجملة العلاج بعد الاختبار تُحيل إلى «هذا الدرس» ولا تسمّي درساً؛ و«فوق أم تحت؟» بترتيب السؤال، والجواب أول الخيارين في ثلث البنود إلى ثلثيها؛ والحلّ المشترك لا يُرسم على مسرح المحاولة السابقة؛ ولكل خطأ في «أيّ أمر اتّبع؟» حلّه؛ وسؤال الخطأ الذي يحتاج أداة الطفل للمواد وحدها؛ ولا «داخل» و«فوق» معاً في صندوق واحد. **وبعد الفحص المستقل D:** موضع الجواب في كل خيارات ثابتة الترتيب («فوق أم تحت؟»، و«في أيّ عربة؟»، و«على يمينه أم يساره؟»، و«نعم/لا»، و«بقي كما هو/تغيّر») في ثلثي بنود النوع على الأكثر في الوحدة وفي بنود المساعدة، ولا يكون واحداً في كل المسار الرئيس للدرس؛ ولا يرسم `together` على مسرح سابق أياً كان اسم معامله؛ ولا تسمّي جملة العلاج درساً ولو بلا علامتي تنصيص؛ والكرسي مرجع للتقييم وحده؛ ولا يُسجَّل حلّ لخطأ روبوت لا يبلغه بند بمساعدة؛ وفي `d240` يُحجز في «ضع في الخريطة» ما يُحفظ: حلقاته وخانة جوابه. **وبعد الفحص المستقل E:** «ضع في الخريطة» في تقييم لا تكون خانة جوابه خانة جواب «ضع» آخر في الوحدة أيّاً كانت القطعة؛ وعلاج «بقي كما هو/تغيّر» فيه بقاءٌ خالص؛ و«نعم/لا» بمساعدة له جملة حلّ؛ و«في آخر الطابور» كلمة حلّه «الأخير»؛ و«أيّ أمر اتّبع؟» بخطأ الجهة برنامجه بانعطافة واحدة؛ و`together` بمعامل مفكّك؛ وتوائم الدرس جديدة بمسار الطفل (`d240`).

### 14.4 الفحص (إضافة إلى 13.6)
`realtap_run.py` يلمس بالإصبع انتظارات S1-U3 كلها (ضع الشيء بالسحب على شاشة وبلمس الحلقة على أخرى، وأزرار الروبوت، وبلاطات الطريق، وتلوين العربات، وأزرار المشاهد)؛ و`quicktap_run.py` اللمس السريع على الطريق بزمن الحركة الحقيقي؛ و`replay_run.py` القسم 8 (بعد فعل الطفل)؛ و`backup_voice_run.py` حزمة الصوت والنسخة الاحتياطية؛ والسائق `deepall` و`remedialdeep` يبلغان الكشف والتوأم في كل بند بمساعدة (`twins missing`)؛ و`items_run.py` كل بند يُقيَّم أو يُراجَع في سياق درسه صحيحاً وخطأً (225 بنداً)، وكل طريق مرسوم لا يقطع قطعة ليست عليه ولا يمرّ بقطعة منه قبل دورها (بنقاط الخط `data-stops`)، وما في اليد مرفوع فوق القدمين، و«ضع النجمة» لا يبدأ والمطلوب صحيح، و«بقي كما هو» بإضافة لا يتلامس فيه شيئان (ثماني مرات لكل بند)، وحساب مناطق اللمس أقل من 25 م.ث على iPhone SE بمعالج أبطأ أربع مرات، ولمسة بالإصبع على حافة جدار الصندوق لا تُسجَّل جواباً؛ و`ladder_run.py` ما رُسم للمحاولة الرابعة باقٍ حين يجيب الطفل، وفي الأنواع التي حلّها رسمٌ يجب أن يكون على المسرح، وهالة اليمين واليسار على اليد اليمنى تحت ما في اليد، وجملة الحلّ لجهة المطلوب، وشارات الحلّ لا تتراكب، و«شاهد التجربة» قبل التجربة (262 بنداً بمساعدة، وبندان من صنع الفحص لمسار لا يبلغه المحتوى)؛ و`replay_run.py` القسم 8 أن «أعد الجملة» في «أيّ أمر اتّبع؟» يعيد حركة الروبوت؛ و`mutants_run.py` أربعون طفرة محتوى وخمس طفرات كود وثمانٍ وعشرون طفرة في المتصفح، يخفق على كلٍّ منها الفحص المعنيّ (و`CONTENT_ONLY=1` للمحتوى وحده).

### 15.3 الصلاحية آلياً (إضافة إلى 14.3)
- **في `d240.mjs`:** «حقيقة» كل مسألة قياس بمهمتها ووحدتها وعددها بلا الشيء، والشيء بوحدته (`HOBJ`)؛ وقراءة العدد من بنائه مسألة واحدة عدّاً وبطاقةً وبناءً؛ والهيئة القريبة (`NEARK`) في النوع الواحد، وبين «أيّها؟» و«رتّب» (صورة الأحجام بنوع الشيء)، وفي `spanPick` بعدد الشبرين وصاحب الجواب، وفي المشاهد (`SCENE_NEAR`)؛ والتعدّي بزوجه؛ ومسائل «معي» المعلنة (`mat.facts`) معروضة في الدرس (`shownOf`).
- **في `lint.mjs` (4ب4–4ب18):** الشيء المقاس مرسوم وما يوزن بثقلين مختلفين (4ب4)؛ موضع الجواب موزّع في كل نوع بخيارات ثابتة (4ب5)؛ الصيغتان بحركة الآخر وبحرف العطف والجرّ وفي التسميات (4ب7)؛ صورة التعليل لا يكون أطولها الأعلى ولا الأبعد (4ب8)؛ طول واحد وسلّة واحدة لكل شيء في الوحدة (4ب9)؛ «سبعةٌ وثلاثةٌ، معاً عشرةٌ» (4ب10)؛ لا يصيب صنفٌ بما يُرى (رتبة البداية والنهاية، والصفّ، واللون) ولا قاعدةٌ طبيعية (صنفٌ واحد، والنهاية وعكسها، والملتوي) أكثر من حدّها في الوحدة والتقييم والمسارات والإتقان، بسياسات التساوي الثلاث، والتوأم في غير موضع أصله وتسلسله (4ب11)؛ «الأكبر أثقل» يقع فيه الطفل في الإتقان (4ب12)؛ ما يُقال قبل الوضع وبعد الميل وفي التوقّع (4ب13)؛ التعدّي لا تجيبه قاعدة لا تقارن في أيّ مسار تمرين أو تقييم درس، وسؤالاه معاً، وتوائمه بفخّ أصلها، وضمير لمسه بجنس الشيئين (4ب14)؛ جنس الشيء كاسمه (4ب15)؛ ما في الحقيبة تذكره «معي» (4ب16)؛ ولكل شيء اسم واحد (4ب17)؛ و«معي» لا تقول أعداد شاشتها، وتعلن مسائلها وكل عدد فيها من مسألة معلنة (4ب18). وفي اللغة: همزة الوصل في الأمر وعين المضارع بجدول مراجَع (`build/vowels.json`)، والكسرة لالتقاء الساكنين قبل همزة الوصل وحدها، و«ـْتَ» و«ـْتِ» و«أَنْتِ» والكاف خارج الصيغتين مخالفة. ومعها: الترتيب بالغرام ونسبة الزوج؛ وسؤال الخطأ الأول سؤال؛ والتسمية في الصفحة بـ `G()`؛ ولا قراءة للمفتاح بغير `isActKey` بأيّ صيغة؛ وبنك المدح (والبنك بحسب البند) موجود. والمولّد يتوقّف على مفتاح مكرّر في أي قاموس (`nodup`). وبعد H1 وH2: صاحب الصفة في البنود ذات الخيارين (الأطول، والأثقل…) وجواب «أيّ القياسين صحيح؟» لا في موضع واحد في مسار أو إتقان أو تقييم (4ب5)؛ والقاعدتان المسمّاتان بعدد الأشياء وما تتعلّمه الوحدة لكل عدد، والعلاج مساراً، والتساوي حلّاً بالنهاية، و«المس الملتوي/المستقيم»، واللون بحقله، والتوأم لا بلون جواب أصله (4ب11)؛ ومسائل «معي» مواصفاتٍ وأعدادها لا خياراً مكتوباً في شاشتها وجواب ما تطلب عدّه مقولاً (4ب18)؛ وجدول الحركة بعد السوابق والمصدر بألفه أينما وقعت و«IV» والمفتاح غير المستعمل، والكسرة لكل كلمة من الزوج؛ وقاعدة المفتاح بما يُفعل بالحدث. وبعد I1 وI2: العلاج على أصوله والتوأم بقواعده، ومراجعة كل مفهوم مسارٌ، وما تتعلّمه الوحدة بمتعادلاتها كلها، وترتيب الألوان الافتراضي من الكود (`LEN_DEF`) (4ب11)؛ وموضع الجواب وموضع صاحب الصفة لكل نوع، والميزان بكفّته، وأنواع الشيئين يميناً ويساراً عائلةٌ تُقاس معاً (4ب5)؛ والمثنّى المرفوع المذكّر عدد (4ب18)؛ و«الِـ» و«لِـ» قبل همزة الوصل، وIV لكل رباعيّ؛ وقاعدة المفتاح بصيغ المستمع كلها؛ وما يُسمع بعد `psleep` بلا البوابة مخالفة. وفي الكلام: لا تبدأ جملةٌ والصفحة مخفية، والإخفاء خارج الدرس يقطع الجملة ولا يُسقطها. وبعد J1 وJ2: ما تتعلّمه الوحدة لكل عدد أشياء وسؤال (`LEARNQ`) في الأبواب، وبنود السؤال الواحد في المسار إن كانت أربعة فأكثر، وموضع التوأم لكل نوع (4ب5)، و«رتّب» في العلاج وفي التوأم لا يُرتَّب بالنهايات إن لم يُرتَّب أصله بها (4ب8 و4ب11)، و«الشيئان أعلى وأسفل» عائلةٌ، ومراجعة المفهوم بسؤاليه المتعاكسين (4ب5)؛ و«ـهُنَّ» و`IVp` و«لِلّـ» والفعل المثنّى بقائمة؛ واسم المفتاح بـ «===» وحدها، والمستمع باستدعائه المباشر، ولا `onkey…` محسوباً، وما يُسمع بعد `psleep` بصيغٍ أخرى. وفي نسخة الفحص حارسٌ يرى ما تُحصى صيغه ولا تُغلق: جملةٌ أو نغمةٌ والصفحة مخفية أو لغير الغطاء الظاهر أو بعد مهلةٍ من شاشةٍ تُركت، و`numberPick` بأقلّ من ثلاثة.

### 15.4 الفحص (إضافة إلى 14.4)
`ws_tap_run.py` يلعب كل لغز في كل ورشة بالإصبع بالترتيبين، وزرّ التدوير لا يغطّي شيئاً؛ و`items_run.py` كل بند يُقيَّم أو يُراجَع صحيحاً وخطأً (313 بنداً)، ومعه مجسّات الوحدة: الجملة العددية بالكتابتين، وما يوضع في الكفّة لا يخترق الذراع، وما ينتظر لا تركبه الكفّتان، والتوقّع من الصورة لا يُحكم، وجملة «ضع» قبل الوضع، وجواب كل بند تعدٍّ بحسابٍ مستقل، وحلقة الأداة مع تقليل الحركة، وطرفا كل شيء يُقاس ليلاً ونهاراً، وجمل الشيء بضميره، وشارات العدّ في كل بنود العدّ (والمبعثر بستّ بذور) داخل المسرح ولا تتراكب، وصفّ «حاذِ» المخفيّ، ولمسة حقيقية داخل حافّة كل عربة على iPhone SE، وسؤال الخطأ
