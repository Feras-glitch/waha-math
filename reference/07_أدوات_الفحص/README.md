# أدوات الفحص

كلها تعمل بـ Python 3 مع Playwright (Chromium) وNode.js. تُنفّذ من مجلد يحتوي نسخة من التطبيق باسم `app.html`، أو عدّل المسار داخل السكربت.

- `smoke.py`: تحميل الصفحة، عدد المفاهيم والدروس، وأخطاء الصفحة.
- `smoke2.py`: جلسة المفهوم (30 تجربة، تكرار داخل الجلسة) وفتح درس p2u7l4.
- `verify.py`: تكرار الأسئلة داخل كل مفهوم، وعدد بنود الفهم.
- `distinct.py`: عدد الأسئلة المتمايزة لكل نوع في كل مفهوم، بين نسختين (يحتاج تعديل المسارات).
- `cmpset.py <قبل> <بعد>`: مقارنة مجموعات الأسئلة لكل مفهوم، وإظهار أي نص سؤال فُقد نهائياً. **الأداة الأهم قبل أي حذف.**
- `dedupe2.py <مصدر> <هدف> [بادئة]`: حذف البنود المكررة حرفياً مع الإبقاء على نسخة الفهم، واستثناء مفهوم C158 (يحتاج تعديل الاستثناء لو أُعيد الحذف).
- `dump_bank.py`: تصدير بنك الأسئلة إلى JSON.

**تحذير:** `dedupe2.py` يعدّل الملف الذي يُعطى له. شغّله على نسخة، لا على الأصل.

**ملاحظة عن الأدوات القديمة:** خطوط البناء السابقة (`build_html.py` و`fix_data.py`) اعتمدت على مسارات مؤقتة في `/tmp` وملفات قديمة، وإعادة تشغيلها قد تستبدل النسخة الحالية. **لا تُعَد تشغيلها.** المصدر الحالي هو النسخة 8.

## أدوات أُضيفت في النسخة 9
كلها تأخذ مسار ملف التطبيق وسيطاً أول، مثل `python3 all_lessons.py /path/app.html`.

| الأداة | ما تفعله |
|---|---|
| `all_lessons.py` | تفتح الدروس الـ158 وتكملها عبر الواجهة، ثم تعرض الدروس الفاشلة وأخطاء الصفحة. |
| `regress_fixes1.py` | اختبارات انحدار للدفعة الأولى: انهيار المراجعة، والتغذية الراجعة، وقفل الاختيار، ورسالة الشارة، وXSS، وتلف التخزين. |
| `regress_fixes2.py` | اختبارات انحدار للدفعة الثانية: `parseNum`، وEnter، وخريطة المراحل الأربع، وزر «تابع»، والمختبر، والمرآة، والبوابة. |
| `touch_mobile.py` | لمس حقيقي على محاكاة Pixel 5 عبر CDP: تمرير بالإصبع، وسحب بالضغطة القصيرة، وعدد الأشباح، والدرس 1. |
| `gen_review.py <app> <out.md>` | يولّد ملف المراجعة مرتباً بالمرحلة ثم الوحدة ثم المفهوم من البنك الحي. |

**تشغيل الفحص الكامل بعد أي دفعة:**
1. `node --check` على كل سكربت.
2. `all_lessons.py`.
3. `cmpset.py` بين النسخة قبل الدفعة وبعدها.
4. اختبارات الانحدار الثلاثة.
